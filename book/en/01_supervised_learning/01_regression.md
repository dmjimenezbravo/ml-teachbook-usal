# 2.1 Regression

(Content translated from Spanish version - Full English version coming soon)

This chapter covers regression, predicting continuous values:

- **Linear Regression**: the simplest model
- **Ordinary Least Squares (OLS)**: exact solution for linear regression
- **Gradient Descent**: general optimization algorithm for any model
- **Polynomial Regression**: capturing non-linear relationships
- **Regularization (Ridge, Lasso)**: preventing overfitting
