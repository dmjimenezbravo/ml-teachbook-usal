# Fundamentals and Introduction to Machine Learning

Welcome to the course **Fundamentals and Introduction to Machine Learning** designed for students of the Faculties of Sciences and Chemical Sciences at the University of Salamanca.

## Purpose of the Book

This book guides you on a journey from classical statistical concepts to modern deep learning models. The goal is for you to **understand how machines learn from data** and for you to be able to build, train, and evaluate models that solve real-world problems.

## Content Structure

The book is divided into three main sections:

### **Section 1: Fundamentals**
Understand the paradigm shift: from fixed-rule programming to data-driven learning.

- Historical origins of AI and machine learning
- Fundamental concepts: data, features, labels
- Evaluation metrics and cross-validation

### **Section 2: Supervised Learning**
Learn to model continuous variables (regression) and categorical variables (classification).

- Linear and polynomial regression
- Linear and non-linear classifiers
- Neural networks

### **Section 3: Unsupervised Learning**
Discover hidden patterns in unlabeled data.

- Clustering (grouping)
- Dimensionality reduction
- Anomaly detection

## Who Is This For?

This course is designed for:
- Undergraduate students in Science, Physics, Statistics, Computer Science, or Engineering
- Anyone interested in machine learning and data analysis
- Professionals looking to update their skills

## Prerequisites

While the book is self-contained, it helps to have:
- Basic Python knowledge or willingness to learn
- Familiarity with linear algebra and calculus (but not required)
- Analytical thinking and patience with mathematical concepts

## How to Use This Book

Each chapter includes:
- **Theoretical concepts** explained clearly
- **Practical examples** with executable Java code
- **Visualizations** to better understand results

It's recommended to follow the established order, though you can consult specific sections as needed.
