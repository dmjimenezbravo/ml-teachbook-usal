# 1.2 Fundamental Concepts

(Content translated from Spanish version - Full English version coming soon)

This chapter introduces the essential vocabulary and concepts for working with machine learning models:

- **Data, Features, and Labels**: The basic structure of datasets
- **Overfitting and Underfitting**: The bias-variance tradeoff
- **Cross-Validation**: Rigorous evaluation without bias
- **Evaluation Metrics**: Precision, recall, F1, AUC for classification; MSE, MAE, RMSE for regression
- **The ML Pipeline**: From data collection through deployment
