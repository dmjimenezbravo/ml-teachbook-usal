# 3.2 Dimensionality Reduction

(Content translated from Spanish version - Full English version coming soon)

This chapter covers techniques to reduce data complexity while preserving essential information:

- **PCA (Principal Component Analysis)**: maximize variance explained
- **t-SNE**: visualize complex relationships in 2D
- **UMAP**: balance between PCA and t-SNE
- **Curse of Dimensionality**: why reduction matters
- **Applications**: compression, visualization, preprocessing
