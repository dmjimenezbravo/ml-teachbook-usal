# Section 2: Supervised Learning

Welcome to the second section of the course. Here we'll learn to build models that learn from labeled examples.

## What is Supervised Learning?

In supervised learning, we have:
- **Data**: input features (X)
- **Labels**: correct answers (y)
- **Goal**: learn the relationship X → y

It's like learning with a "supervisor" who tells you if your answers are correct.

## Two Types of Problems

### 1. Regression
We predict a **continuous value** (a real number):

- Predict house price
- Predict tomorrow's temperature
- Predict rainfall amount
- Predict population growth

### 2. Classification
We predict a **category** or **class**:

- Diagnose if a person has a disease (yes/no)
- Classify emails as spam or legitimate
- Recognize if an image is a cat, dog, or bird
- Predict if a customer will churn

## What You'll Find in This Section

### Chapter 2.1: Regression
- Linear Regression: the simplest and most fundamental model
- Ordinary Least Squares: how regression trains
- Gradient Descent: the optimization algorithm
- Polynomial Regression and Regularization: more complex models

### Chapter 2.2: Classification
- Logistic Regression: binary classification
- Confusion Matrix and Metrics: evaluating classifiers
- Decision Trees and Random Forests: interpretable models
- Support Vector Machines: optimal separation
- Ensemble Methods: combining multiple models
- Neural Networks: introduction to deep learning

## Recommended Structure

It's recommended to learn in this order:

1. **Linear Regression** → understand fundamentals
2. **Gradient Descent** → understand how models learn
3. **Polynomial Regression** → handle non-linearity
4. **Logistic Regression** → extend regression to classification
5. **Classification Algorithms** → learn multiple approaches
6. **Ensemble Methods** → combine model strengths
7. **Neural Networks** → the future of machine learning
