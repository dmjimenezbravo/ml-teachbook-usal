# 2.2 Classification

(Content translated from Spanish version - Full English version coming soon)

This chapter covers classification, predicting categorical variables:

- **Logistic Regression**: binary classification with sigmoid
- **Confusion Matrix**: visualizing classifier performance
- **Metrics**: Precision, Recall, F1-Score, AUC-ROC
- **Decision Trees**: interpretable but prone to overfitting
- **Random Forest**: ensemble of trees
- **Support Vector Machines**: optimal hyperplane separation
- **Gradient Boosting**: sequential error correction (XGBoost, LightGBM)
- **Neural Networks**: introduction to deep learning
