# 3.3 Anomaly Detection

(Content translated from Spanish version - Full English version coming soon)

This chapter covers techniques for identifying rare and unusual patterns:

- **Fundamental Concepts**: point, contextual, collective anomalies
- **Statistical Methods**: Gaussian univariate approach
- **Distance-based Methods**: k-NN, LOF
- **Isolation Forest**: efficient tree-based approach
- **Autoencoders**: neural network approach
- **Evaluation Metrics**: Recall more important than Accuracy
- **Applications**: fraud detection, preventive maintenance, intrusion detection
